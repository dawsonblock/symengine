# Historical record

These are dated documents: milestone reports, per-version test reports,
earlier qualification reports, upgrade and release notes, and the
pre-3.3.3 README. They explain how SIS reached its current state and are
kept for provenance. They are **not current claims**. Where they
disagree with the operational documents, the operational documents win.

For the current documentation, start at [../INDEX.md](../INDEX.md).
The `v3/` subdirectory holds the historical v3 gate and qualification
reports.
